# سیاست نصب LocalChat 2.0

هدف انتشار، یک فایل واحد `LocalChat-Setup-2.0.0.exe` است؛ نه نسخه Portable.

- فایل Setup تمام فایل‌های خود برنامه را درون خود دارد.
- PyInstaller runtime پایتون و کتابخانه‌های موردنیاز برنامه را داخل payload قرار می‌دهد؛ رایانه مقصد به Python نیاز ندارد.
- Setup در صورت نبودن، Microsoft Visual C++ Redistributable x64 و Microsoft Edge WebView2 Runtime را از لینک‌های رسمی مایکروسافت دانلود و نصب می‌کند.
- نصب Ollama، دانلود مدل‌های زبانی/بینایی، مدل‌های گفتار، موتورهای STT/TTS و افزونه‌های اختیاری درون برنامه و با انتخاب کاربر انجام می‌شود؛ این فایل‌ها در Setup پایه قرار نمی‌گیرند.
- اتصال اینترنت برای دریافت پیش‌نیازهای مفقود در زمان نصب لازم است.
- برنامه و فایل‌های کاربر در مسیرهای جداگانه نگهداری شوند تا حذف برنامه مکالمات و تنظیمات را پاک نکند.

## مرکز راه‌اندازی داخل برنامه (۲.۰.۲۱)

- برنامه حتی بدون Ollama باز می‌شود؛ دکمهٔ «⚙ راه‌اندازی» در نوار بالا وضعیت همهٔ اجزا را نشان می‌دهد.
- نصب خودکار: Ollama (نصب‌کنندهٔ رسمی، بی‌صدا) و موتور صدا (Python همراه + faster-whisper + Edge TTS در `%LOCALAPPDATA%\LocalChat\voice\audio-python`).
- دانلودها با HTTP Range ادامه‌پذیرند، با فاصلهٔ زمانی تلاش دوباره می‌کنند و اگر برنامه وسط کار بسته شود، در اجرای بعدی خودکار ادامه می‌یابند. مدل‌های Ollama هم لایه‌به‌لایه ادامه می‌یابند.
- پیشنهاد مدل بر اساس VRAM/RAM واقعی؛ مدل‌هایی که جا نمی‌شوند علامت «بزرگ» می‌گیرند.
- مسیر دستی: ollama.exe، پوشهٔ مدل‌های Ollama، python.exe محیط صدا، پوشهٔ ParsVoice.
- ParsVoice (صدای آفلاین) نصب خودکار ندارد (مجوز Hugging Face و محیط Coqui TTS جداگانه)؛ فقط تشخیص و مسیر دستی.
- نصب‌ها مثل دانلود مدل نیاز به تأیید هویت سازنده دارند.

## بدون دانلود در ساخت و نصب (۲.۰.۲۴)

- `build_installer.bat` چیزی از اینترنت نمی‌گیرد: ترجمهٔ فارسی در `packaging\Farsi.isl` همراه پروژه است و ابزارهای ساخت (PyInstaller، NumPy و ...) فقط وقتی نصب نباشند — و فقط روی رایانهٔ ساخت — نصب می‌شوند.
- `LocalChat-Setup-*.exe` هم هیچ‌چیز دانلود نمی‌کند. Visual C++ و WebView2 هم مثل Ollama و مدل‌ها بعد از نصب از «⚙ راه‌اندازی» داخل برنامه نصب می‌شوند. بدون WebView2 برنامه در مرورگر باز می‌شود.
