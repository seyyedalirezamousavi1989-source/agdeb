# اصلاح رگرسیون جست‌وجوی رسانه — 2.0.15

## علت
در مسیر درخواست‌های ویدئو، پس از دریافت نتایج معتبر از منبع تخصصی، یک جست‌وجوی عمومی وب جداگانه نیز اجرا می‌شد. در برخی محیط‌ها پاسخ عمومی شامل رکوردهایی بدون فیلد `kind` بود؛ ادغام این رکوردها با نتایج رسانه باعث شکست قرارداد پاسخ API و وابستگی رفتار به وضعیت شبکه/ارائه‌دهنده‌ها می‌شد.

## اصلاح
- مسیر رسانه اکنون از `media_search.search_media` برای منابع تخصصی و fallback وب استفاده می‌کند.
- وقتی نتیجه رسانه‌ای موجود است، همان فهرست نرمال‌شده با `engine=media` برگردانده می‌شود.
- جست‌وجوی عمومی دوم اجرا نمی‌شود؛ بنابراین نتایج رسانه‌ای همگی قرارداد فیلدهای یکسان از جمله `kind` را حفظ می‌کنند.
- محدودیت‌های صریح جست‌وجو همچنان از مسیر عمومی قبلی عبور می‌کنند و تغییر نکرده‌اند.

## اعتبارسنجی
- `test_media_and_version.py`, `test_search_routing_regressions.py`, `test_search_engine.py`: تعداد 40 تست موفق.
- اجرای کامل pytest در محیط ساخت به سقف زمانی محیط رسید؛ نتیجه کامل برای کل مجموعه ادعا نمی‌شود.
